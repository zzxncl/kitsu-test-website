ambient-light.js

Drop-in ambilight for any <video>. It samples frames, blurs them behind the player, and optionally lights the whole page. Hit play — then grab the file.

Mode Page

Use it

<!-- 1. the file -->
<script src="ambient-light.js"></script>

<!-- 2. one line -->
<script>
  const amb = AmbientLight.attach('video');
</script>

That's the whole integration. It injects its own CSS, wraps the video itself, and starts and stops with playback.

Options

new AmbientLight(video, {
  mode:          'full',   // 'off' | 'soft' | 'full' | 'neon' | {custom}
  flood:         true,     // also light the page behind the document
  floodStrategy: 'auto',   // 'behind' | 'overlay' | 'auto'
  target:        null,     // container to glow around (default: wraps the video)
  fps:           null,     // override the preset's repaint rate
});
CallDoes
amb.setMode('neon')Switch intensity preset.
amb.cycle()Step through off → soft → full → neon.
amb.setFlood(false)Keep the glow to the frame only.
amb.toggle()Off ↔ full.
amb.destroy()Remove everything and restore the DOM.

Things worth knowing

Cross-origin video is fine. It only ever draws frames and never reads pixels back, so a tainted canvas costs nothing. No CORS headers, no crossorigin attribute needed.

The page flood needs somewhere to live. A layer at z-index:-1 is invisible if <body> paints an opaque background over it. On auto it detects that and moves the colour up to <html> — the page looks identical and the glow has room. If it can't do that safely it falls back to an overlay layer using mix-blend-mode: screen, which works anywhere.

It's cheap. Frames go into 40×23 canvases at 8–15fps, and the browser's own upscaling does the smoothing. It stops entirely while paused.

Watch your contrast. With flood on, text sitting directly on the page background can wash out in bright scenes. Give that text a backing text-shadow, or make your surfaces slightly translucent so the colour reads through them.
